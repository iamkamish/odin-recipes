# odin-recipes

[Project: Recipes](https://www.theodinproject.com/lessons/foundations-recipes) —a hands-on exercise for the HTML Foundations course from [The Odin Project](https://www.theodinproject.com/).

Brief description:
"In this project, you are going to build a basic recipe website.
The website will consist of a main index page which will have links to a few recipes."

## In this project, I practiced the following skills:
- HTML Boilerplate
- Headings
- Paragraph
- Unordered lists
- ordered lists
- Absolute and relative links 
- Opening links in a new tab
- displaying images
- Alt attribute
- Using Git and GitHub
- Using Terminal
- Using Visual Studio Code
